# RoboticArm_6DOF_servos
This personal technical project is the first robotic system I developed.
Its purpose is to explore and improve essential skills in robotics and mechatronics such as :
- Mechanical design
- 3D printing
- Inverse kinematics
- Programming
- Electronics integration

This robot was designed, modelled and assembled entirely from scratch using 3D printed parts, servo motors (DM996) and M4 bolts and screws
(except the mechanical gear imported from cults3d)

This project has demonstrated basic principles of robotic manipulation but revealed many flaws:
- very noticeable backlash from all the servos combined
- lot of play on the side due to asymmetrical design
- jittery real-time control due to the discrete angular resolution of the servos 
 I plan to solve these issues and to improve using stepper motors with reductors instead of servo motors
